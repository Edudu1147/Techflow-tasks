# Processo de Realização do Projeto — TechFlow Tasks

O projeto **TechFlow Tasks** foi estruturado com foco em organização de tarefas, testes automatizados, padronização de código e integração contínua.

## Etapas executadas
1. **Estruturação do repositório e código:** organização dos módulos em `src/techflow`, suíte de testes em `tests/` e arquivos de configuração (`pytest.ini`, `requirements.txt`, `requirements-dev.txt`).
2. **Automação de CI/CD:** configuração do workflow no GitHub Actions (`.github/workflows/ci.yml`) para executar lint com `flake8` e testes automatizados com `pytest`.
3. **Gestão visual e escopo:** acompanhamento das atividades em quadro Kanban (GitHub Projects) com colunas de andamento e registro de ajustes de escopo ao longo da execução.
4. **Documentação e apresentação:** consolidação das informações teóricas, evidências do repositório e preparação do vídeo pitch.
